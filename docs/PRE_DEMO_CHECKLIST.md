## 🚀 Demo Day

### Morning (arrive by 08:30)
- [ ] Arrive early, get settled
- [ ] Find power outlet, plug in laptop
- [ ] Connect to venue Wi-Fi
- [ ] Open terminal, navigate to project
- [ ] Run `start_all.sh`
- [ ] Wait 2–3 minutes for all services to start
- [ ] Verify all 4 services are running
- [ ] Open browser tabs: Swagger, Dashboard, Landing
- [ ] Open Expo Go on phone, scan QR code
- [ ] Test one full demo flow

### Before Judging
- [ ] Laptop plugged in and charging
- [ ] Phone charged and connected
- [ ] All services running and verified
- [ ] Browser tabs open and ready
- [ ] Mobile app loaded and ready
- [ ] Demo script printed and in hand
- [ ] Backup video queued and ready

### During Demo (3 minutes)
- [ ] Open with the problem (15 sec)
- [ ] Show operator dashboard (30 sec)
- [ ] Show Swagger UI (30 sec)
- [ ] Live demo: request OTP (15 sec)
- [ ] Live demo: verify OTP (15 sec)
- [ ] Live demo: browse routes (10 sec)
- [ ] Live demo: book trip (20 sec)
- [ ] Switch to dashboard (15 sec)
- [ ] Close with impact (10 sec)

### If Something Breaks
- [ ] Stay calm, smile
- [ ] Say "Let me show you the backup video"
- [ ] Play pre-recorded demo
- [ ] Continue with pitch
- [ ] Judges understand — live demos are hard!
